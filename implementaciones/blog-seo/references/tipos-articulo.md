# Referencia — Tipo de artículo (formato)

Antes de escribir hay que decidir **qué tipo de contenido** se crea. El formato
no es estético: define la estructura, el tono, la longitud y el CTA. Se elige en
función del **objetivo del artículo** y de la **intención de búsqueda**.

## Catálogo de tipos

| Tipo | Para qué sirve | Estructura típica | Encaja con intención |
|---|---|---|---|
| **Guía completa** | Autoridad sobre un tema amplio; suele ser el **pilar** | Definición → subtemas en H2 → FAQ → conclusión | Informativa (amplia) |
| **Tutorial paso a paso** | Enseñar a hacer algo concreto | Requisitos → pasos numerados → resultado → errores | Informativa (how-to) |
| **Comparativa (X vs Y)** | Ayudar a decidir entre opciones | Criterios → tabla comparativa → recomendación honesta | Comparativa / comercial |
| **Lista ("10 consejos…")** | Contenido escaneable y compartible | Intro breve → ítems con H2/H3 → cierre | Informativa / comercial |
| **Errores frecuentes** | Generar confianza mostrando experiencia | Error → por qué pasa → cómo evitarlo | Informativa / comercial |
| **Caso de éxito** | Prueba social; apoyar la venta | Contexto → problema → solución → resultados | Comercial / transaccional |
| **Preguntas frecuentes (FAQ)** | Resolver dudas previas a la compra | Bloques pregunta → respuesta clara | Informativa / comercial |
| **Tendencias** | Actualidad; posicionar como referente | Contexto → tendencias → implicaciones | Informativa |
| **Opinión / análisis** | Voz de marca, diferenciación | Tesis → argumentos → conclusión | Informativa |
| **Mitos y realidades** | Corregir creencias, educar | Mito → realidad → explicación | Informativa / comercial |
| **Checklist** | Utilidad accionable, captar leads | Intro → lista verificable → descargable/CTA | Informativa / comercial |
| **Glosario** | Captar long-tail y dar contexto | Términos ordenados → definición breve | Informativa |

## Cómo elegir (objetivo + intención → tipo)
1. Parte de la **intención** (informativa/comercial/comparativa/transaccional).
2. Cruza con el **objetivo** del artículo:
   - Atraer tráfico amplio (TOFU) → guía, lista, tutorial, glosario, tendencias.
   - Educar/diferenciar (MOFU) → comparativa, errores frecuentes, mitos, FAQ.
   - Apoyar la venta (BOFU) → caso de éxito, comparativa, checklist con CTA fuerte.
3. Comprueba la **SERP**: si Google muestra sobre todo un formato para esa
   keyword, respétalo (es la intención revelada) salvo que puedas ganar con un
   ángulo mejor.
4. **Pilar vs cluster**: los pilares suelen ser *guía completa*; los clusters,
   formatos más específicos (tutorial, comparativa, errores, FAQ…).

## Reglas
- El tipo se decide **antes** del esquema y se **justifica** en el documento.
- La estructura del artículo debe ser fiel al tipo (una comparativa lleva tabla;
  un tutorial, pasos numerados; una lista, ítems paralelos…).
- No mezclar dos tipos sin criterio: un artículo puede tener FAQ al final sin ser
  "tipo FAQ"; el tipo es el formato **dominante**.
